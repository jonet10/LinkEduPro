# LinkEduPro Frontend (Web/PWA)

Application web LinkEduPro (Next.js App Router) + Tailwind CSS.

## Démarrage (local)

```bash
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

## Build

```bash
cd frontend
npm run build
npm start
```

## PWA (installation)

- Manifest: `frontend/public/manifest.webmanifest`
- Service Worker: `frontend/public/sw.js`
